# Dataset Attribution

**Dataset:** Wine  
**Provider:** UCI Machine Learning Repository  
**Dataset page:** https://archive.ics.uci.edu/dataset/109/wine

The Wine dataset contains 178 samples described by 13 continuous chemical measurements and a class/cultivar label. In this project, the class label is kept separate and is **not used for unsupervised model training**.

Please preserve the original dataset attribution when publishing the project.
